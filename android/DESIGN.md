# Tacit Android

1. 方向：像一本按天写的日记，用暖灰纸面呈现录下的对话；录音是默认开着的来源，不当主角。界面跟随系统深浅色。
2. 色板：沿用 docs/ui.md。正文用 ink，阅读正文用 readingBody，次要文字用 muted，faint 用于分隔和图形。铜绿用于主要操作、选中导航、开关、主体时间线圆点、正常标记和“我”的转写标签。胭脂用于错误、待处理状态、录音状态及危险操作。
3. 字体：12/18、15/24、18/26、24/32sp 四级。正文 400、行标题 500、页标题 600。日期、详情标题和对话列表里的第一句用系统衬线。时间和数字启用等宽数字。
4. 组件：控件 6dp、分组 10dp、浮层 14dp。分组用 raised 底和 1dp 分隔线。文字可随系统缩放，触控区至少 48dp，图标按钮有可读标签。
5. 布局：只有一页对话，不设底栏，页首左边是今天的宋体日期，右上角是设置。设置、详情和子页使用带返回按钮的顶栏。对话页左边留 20dp，设置页左右留 16dp，阅读正文留 20–24dp。
6. 对话与时间线页：没有录音按钮，正常录音时不写状态；录音没开时页首一行“录音没有开启”配“开启”按钮，一次完成授权和开始；有问题时一行，能处理的可点进对应设置，处理不了的（外放、麦克风被占用）只写原因。首次声纹确认只展示一条可试听的候选。查看权限下展示中枢整理的各来源时间线、当天概述和当天草稿，并保留尚未被覆盖的本机录音；未配对或仅采集权限下展示本机对话。一次看一天，日期用宋体 24sp，下面一行写“今天”“昨天”和星期，右侧前一天 / 后一天箭头只跳到有内容的日子。每段左列 56dp 写开始时刻，右边是手机或 Mac 写的标题（宋体 18/26，最多两行）和总结（正文色 muted，最多三行），还没有总结时优先取自己说的最具信息量的一句（跳过过短语气词，没有再用对方原话），草稿/未整理段用空心圆点、不加文字标签，行间只留白不画线。详情页先是标题、总结和要点，再是整理过的原文；中枢段点开时按需联网读取原文。声音管理在语音转写设置。没认出你声音、未转写的录音每天合成一行计数，左列画一道短线。没有内容时用宋体淡字写一句“说过的话，会按天写在这里。”
7. 设置：第一行是录音开关，整行可点。行只显示用户选的值和要处理的问题，正常状态不写字。后台运行按清单展示可验证状态，通过的项只打勾，系统无法查询的项目提示用户确认。“AI 总结”开着时这一行写模型名，出错时写原因；子页是一个开关、一句隐私说明、服务地址 / 模型名 / API Key 三个输入框和“测试连接”，改过才出现“保存”，已存的 Key 只在输入框标签里写“已设置”。
8. 文案：每处说明一句。时长和计数带单位。复制和删除用稳定动词，删除保留确认。加载用铜绿细进度线。界面示例用虚构数据。
9. 动效：只为状态变化服务，三档节奏与 Mac、官网一致，常量全在 `ui/Motion.kt`。quick 150ms（松手、图标或文字小换、箭头旋转、颜色）；standard 进 250ms、退 200ms（展开收起、提示行进出、加载→内容、草稿→总结），列表让位用无回弹弹簧；page 推入 320ms、返回 260ms、旧页退出 200ms（页面层级、换天按方向轻移淡入）。不回弹、不缩放大块内容、不做装饰动画；滚入视口的行、深浅色切换不做过渡；按下即时。本机读取的进度线等 300ms 才淡入，不用骨架屏和“正在加载”。系统“移除动画”时只留淡入淡出或瞬切。
