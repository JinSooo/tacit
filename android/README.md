# Tacit for Android

Tacit 在本机记录手机上的对话、聊天通知和应用使用时长。历史页支持按文字、日期和来源查找，可以手动补写、修正或删除记录。长按桌面图标可直接补写，也可从“设置 → 快捷补写”添加独立桌面入口。其他应用分享的文字要经你确认才会保存为补写。

| 来源 | 记录内容 |
| --- | --- |
| 麦克风 | 录音在设备上加密暂存，只有在相同场次的保留素材中识别到已确认的“我”，才会在本机转写并写入历史。 |
| 聊天通知 | 默认只选微信。在“设置 → 数据源 → 聊天通知”添加或移除应用。只保存通知预览提供的会话名、发送人和正文。系统折叠、截断或隐藏时，可读到的内容会减少。 |
| 应用使用 | 应用和前台使用时段。授予使用情况访问后，打开 Tacit 和系统调度时检查。 |

在设置中按需启用来源和授权。录音需从录音页手动启动，首次使用时试听并确认“这是我”。语音模型在录音设置中下载或从已校验的本地模型目录导入。转写使用 SenseVoice CPU 模型，支持的骁龙 8 Gen 3 设备可选 QNN 加速并回退到 CPU。HyperOS 的自启动和电量管理入口见“设置 → 后台运行”。

历史保存在 SQLCipher 数据库中，密钥由 Android Keystore 保护，写入前会脱敏。当前版本的记录只保存在手机。覆盖安装需沿用原签名和 `top.jinso.tacit` 包名。0.3.0 的历史仍能在本机查看、修正和删除。

## 构建

Android SDK 35、JDK 17、已缓存的 Gradle 依赖，以及 `app/libs/` 下的两份 sherpa-onnx AAR。应用打包 arm64-v8a 的 QNN 兼容 AAR。CPU AAR 是生成它时使用的上游依赖。

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export ANDROID_HOME="$HOME/Library/Android/sdk"
./scripts/verify.sh
```

两份 AAR 已在本地时，上述验证不联网。缺少 AAR 时，`scripts/prepare-speech.sh` 从固定的上游产物准备并校验依赖，这一步需要网络或已填充的产物缓存。语音模型在应用内单独准备。

更多验证步骤见 [验证说明](docs/verification.md)。
