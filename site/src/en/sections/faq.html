Frequently asked questions

Can I replay my screen?

Tacit keeps no screenshots or video to replay. Screen records provide app names, titles and time spent. Tacit summarizes what you did and decided from AI sessions, chats and recordings, with links to the original records.

Why does macOS block Tacit the first time?

Tacit uses a self-signed certificate without Apple notarization. Allow Tacit to open once. Updates use the same certificate and keep the permissions you granted.

Can I run my own model?

Yes. Set the summary model to your own OpenAI-compatible endpoint. You can also use Claude Code or Codex if you’re signed in locally. These tools use their own model settings.

Which devices can run Tacit?

Tacit runs on Apple silicon Macs with macOS 14 or later and arm64 phones with Android 9 or later. Android records and transcribes audio on the phone. Pair it for encrypted sync over your local network or the relay mailbox and view the full timeline. You can also use it on its own with optional conversation summaries. A Windows app is planned. You can run the background service with Docker on Windows or Linux today. Intel Macs are unsupported. iOS is still being explored.

Can AI tools change my records?

AI tools can search and read records. They can add a record only when you ask, and cannot edit or delete one. You can correct what AI remembers from a project page or task.

How much does it cost?

Tacit is free and open source under the MIT license. Summaries use your API or account allowance. Change the update frequency or set a daily token limit in settings. Tacit pauses summarizing for the day when you reach that limit.

Which AI tools can connect?

Any AI tool with MCP support can search or add records. Claude Code, Codex, Claude Desktop, and Antigravity connect from settings, and AI tools can check current project progress before they start. Choose a separate summary model from Anthropic, an OpenAI-compatible endpoint, a custom service, or your signed-in Claude Code or Codex.

Can Tacit record WeChat conversations?

Yes. WeChat is an optional macOS source and is off by default. When enabled, Tacit reads the WeChat window and separates the conversation into messages.
