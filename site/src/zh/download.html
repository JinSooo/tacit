下载 Tacit-{{MAC_VERSION}}.dmg

首次打开与系统放行

  1. 拖进“应用程序”

    打开下载的 Tacit-{{MAC_VERSION}}.dmg，把 Tacit 拖进“应用程序”文件夹。

  2. 首次打开 Tacit

    从“应用程序”打开 Tacit。安装包使用固定的自签名证书，未经过 Apple 公证，首次打开时系统会拦下。先点完成，再到系统设置 › 隐私与安全性，找到 Tacit，点仍要打开并输入开机密码。

    如果没有看到这个按钮，在终端运行下面的命令，再打开 Tacit。

    xattr -dr com.apple.quarantine /Applications/Tacit.app

  3. 完成初始设置

    首次打开时主窗口会自动弹出，后台服务也会自动准备。按时间线顶部的清单完成权限授权、整理模型配置和连接 Claude Code / Codex；之后关掉窗口，Tacit 会留在菜单栏继续记录。

Android

当前设备

arm64 · Android 9 或更新 · 发布版 {{ANDROID_RELEASE_TAG}}

下载 Tacit-{{ANDROID_VERSION}}.apk

配合 Mac 扫码配对

安装 Tacit-{{ANDROID_VERSION}}.apk 并开启本机录音与转写。在 Mac 的设置 › 设备生成配对二维码，用手机扫码即可端到端加密同步，并在手机上查看完整时间线。

独立使用

没有 Mac 也可以单独使用 Android 端。录音在手机本机完成转写，也可在设置里按需开启手机端单场 AI 总结。

独立服务端（Docker）

Linux 与 Windows · linux/amd64 与 linux/arm64 · ghcr.io/jinsooo/tacit-hub

服务端部署说明

后台服务默认在 Mac 本机运行，不需要额外服务器。如果希望多台设备共用一个 24 小时在线的加密后台，可在 Linux 服务器或装有 Docker Desktop 的 Windows 电脑上拉取官方镜像运行。

docker pull ghcr.io/jinsooo/tacit-hub:{{HUB_VERSION}}

即将支持与历史版本

Windows 当前设备
Windows 客户端计划支持，敬请期待；目前可先通过 Docker Desktop 在 Windows 上部署后台服务。
iOS 与 Intel Mac 当前设备
iOS 端仍在调研中，暂未发布；Intel 芯片 Mac 暂不支持。
