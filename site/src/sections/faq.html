常见问题

和录屏回放类工具有什么不同？

Tacit 从 AI 会话、聊天和录音里整理你做过的事和做过的决定，每条结论都能点回原文。屏幕记录提供应用、标题和时长。Tacit 不保存截图，也没有画面回放。

第一次打开为什么被系统拦下？

安装包用固定的自签名证书签名，未经过 Apple 公证。首次放行后，后续升级沿用同一张证书，已授予的系统权限会保留。

可以用自己部署的模型吗？

可以。整理模型支持自定义地址，你可以填自己部署的 OpenAI 兼容接口。也可以选本机已登录的 Claude Code 或 Codex，这些工具仍按自己的设置调用模型。

支持 Intel Mac、Windows 或手机吗？

目前只支持装有 macOS 14 或更新系统的 Apple 芯片 Mac。Android 排在 Mac 版验收完成之后。

AI 会不会把我的记录改乱？

AI 工具可以查询记录，只有你明确要求时才会追加内容。它没有修改或删除记录的权限。AI 记错了，你可以在项目页或事项里纠正。

要花多少钱？

应用本身免费开源，采用 MIT 许可证。整理每 15 分钟跑一轮，调用模型会消耗你的 API 额度或账号用量。具体用量取决于当天活动量、是否整理导入的历史，以及你选的模型。

支持哪些 AI 工具？

Claude Code 和 Codex 都能主动查询记录，并在新会话带入当前项目的进展。整理用的模型可以单独选，支持 Anthropic、OpenAI 兼容接口、自定义服务地址，以及本机已登录的 Claude Code 或 Codex。
