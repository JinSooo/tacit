下载 Tacit

下载 Mac 版 下载 Android 版

Windows 客户端计划支持，敬请期待；目前可先通过 Docker 在 Windows 上独立部署后台服务。

iOS 端仍在调研中，暂未发布；可先在 Apple 芯片 Mac 或 Android 手机上使用。

Apple 芯片 Mac（macOS 14+）、Android（arm64，Android 9+），Windows 敬请期待

Mac 端开始使用

  1. 拖进“应用程序”

    打开下载的 Tacit-<版本号>.dmg，把 Tacit 拖进“应用程序”。

  2. 首次打开 Tacit

    从“应用程序”打开 Tacit。如果系统拦下，先点“完成”，再到系统设置 › 隐私与安全性，找到 Tacit，点仍要打开并输入密码。

    如果没有这个按钮，在终端运行下面的命令，再打开 Tacit。

    xattr -dr com.apple.quarantine /Applications/Tacit.app

  3. 完成初始设置

    首次打开时主窗口会自动弹出，后台服务也会自动准备。按时间线顶部的清单完成授权与配置；之后关掉窗口，Tacit 会留在菜单栏继续记录。

Android 端

安装 Tacit-<版本号>.apk（arm64，Android 9 或更新），开启本机录音与转写。在 Mac 的设置 › 设备生成配对二维码，扫码即可端到端加密同步并在手机上查看时间线；也可以单独使用，在设置里可选开启手机端单场 AI 总结。

独立部署后台服务（可选）

后台默认在 Mac 本机运行，不需要服务器。若希望多台设备共用独立后台，可在 Linux 服务器或装有 Docker 的 Windows 电脑上拉取 ghcr.io/jinsooo/tacit-hub 镜像运行，详见 服务端部署说明。
