# Tacit 常见问题

反馈时请附上**现象、发生时间和诊断信息**。在 Tacit 打开 **设置 › 维护 › 诊断信息**，点“预览并复制…”，确认后点“复制”。应用打不开时，可以先提供现象和发生时间。

请勿分享整个数据目录、密钥备份或带访问令牌的链接。

## 打不开或被系统拦截

把 Tacit 从安装盘拖进“应用程序”，从那里打开。若首次打开时系统提示无法验证开发者，确认安装包来自项目发布页后，打开 **系统设置 › 隐私与安全性**，在“安全性”下点“仍要打开”，按系统提示确认。反馈时附上系统提示和 Tacit 版本。 [Apple 的打开方式说明](https://support.apple.com/en-us/102445)

## 后台服务起不来

看 Tacit **时间线顶部**的“还差几步”。后台还在准备时会显示“正在准备后台服务…”；准备失败时会写出原因，并提供“重新准备”和“打开日志文件夹”。先点“重新准备”试一次；仍然失败时，反馈里附上这行提示和诊断信息，日志原文留在本机即可。

## 没有记录或某个来源缺失

打开 **设置 › 数据源**，选中缺失的来源，查看开关、权限、状态和上次运行时间。也可以从时间线切到“详细”，检查对应时段是否有原始记录。反馈时写明来源名称和显示的状态。

## 整理一直没更新

1. 先看时间线顶部的“还差几步”（首次打开会自动展开），那里会直接写出缺什么，例如没装 Claude Code 或 Codex、密钥不对或额度用完。也可以在清单里直接点“测试连接”。
2. 打开 **设置 › AI 模型**。如果有报错，点错误行下面的“查看原因”（只在这台 Mac 上显示）看具体情况，并点“测试连接”。改过模型后看到“连接正常，保存后生效”，记得点“保存”才会生效。
3. 开了代理软件的 Mac，后台联网会自动使用 macOS 的 HTTP/HTTPS 系统代理。PAC 自动代理暂不支持，连不上时请把代理软件切到“系统代理/全局”或 TUN 模式后再试。

反馈时把“查看原因”里的内容连同 **设置 › 维护 › 诊断信息** 里复制的内容一起发来。

## 录音没转写

打开 **设置 › 数据源 › 录音**，检查麦克风权限、选中的麦克风和待转写状态。若时间线顶部提示确认“我”的声音，先完成确认。反馈时写明录音时段、是否在开会及待转写状态。

## 闪退

打开 macOS 的**控制台**，在侧栏选择“崩溃报告”，按发生时间找 Tacit 进程的 `.ips` 文件。反馈时写明闪退前的操作。需要提供崩溃报告时，先检查其中的个人路径和其他私人信息。 [Apple 的崩溃报告说明](https://support.apple.com/zh-cn/guide/console/cnsl664be99a/mac)
