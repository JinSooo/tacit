# 界面规范

Mac 客户端和中枢网页共用这一套。改界面前先读，改完对照第 6 节自查。

## 1. 用词

界面只用左列的词，右列是代码和设计文档里的内部叫法。

| 界面用词 | 内部叫法 | 说明 |
| --- | --- | --- |
| 历史记录 | History、records | 侧栏、搜索框、"打开历史记录" |
| 事项 | thread、线程 | 一件在做的事，如"修复登录页" |
| 项目 | project | 不变 |
| 整理 / 更新 | 提炼、distill | "6 分钟前更新"；维护页的"整理启用前的历史" |
| 后台服务 | 中枢、hub | 设置分组、状态页 |
| 网页版 | 中枢网页 | |
| 自动带入 | 注入、inject | "新会话开始时带入" |
| AI 工具 | Agent | Claude Code、Codex 等 |
| 实时整理 / 每小时汇总 / 每日日记 | 分钟档 / 小时档 / 天档 | 模型档位 |
| 截图识字 | OCR 兜底 | 数据源名 |
| 提供商 | provider | 模型设置 |
| 依据 | evidence、证据 | 事实背后的原始记录 |
| 补写 | manual.note | 用户手动添加的记录 |

同一个动作只用一个动词：打开、添加、删除、修正、同步、导入、整理、连接、断开、暂停、继续、导出。不用"立即""马上"催促。

## 2. 颜色

一页只有一个强调色：铜绿。错误和需要处理的状态用胭脂，只染文字和小图标，不铺大面积红底。灰全部是暖灰。

| 名称 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| accent 铜绿 | `#3B7468` | `#7DB8A9` | 选中、主按钮、链接、当前位置 |
| on-accent | `#FFFFFF` | `#181716` | 强调色上的文字 |
| attention 胭脂 | `#9D2933` | `#E58A8F` | 错误、缺权限、录音中 |
| ink | `#1C1B1A` | `#F2EFEA` | 正文 |
| muted | `#6E6860` | `#A8A197` | 次要文字（对比度 ≥ 4.5） |
| faint | `#A39D94` | `#5E5953` | 只用于图形和分隔，不用于文字 |
| line | `#E7E3DC` | `#2F2C29` | 分割线 |
| paper | `#FBFAF7` | `#181716` | 页面底色 |
| raised | `#FFFFFF` | `#211F1D` | 分组底色 |
| fill | ink 5% | ink 6% | 时间轴轨道、输入框、悬停 |

状态正常不上色，只有出问题才用胭脂。来源、项目、事实类型不再各配一种颜色：时间轴每行已经写了来源名，项目和事实类型有文字和图标。

## 3. 字体

一页最多 4 种字号，从下面 5 级里取：

| 级别 | Mac | 网页 | 用途 |
| --- | --- | --- | --- |
| caption | 11 | 12px | 时间、计数、次要说明 |
| body | 13 | 14px | 正文、列表、按钮 |
| title | 17 | 18px | 卡片标题、分组标题 |
| heading | 22 | 24px | 页面主标题、日期 |
| display | 26 | 28px | 只用于"此刻"的一句话摘要 |

- 宋体只用于 title 及以上级别的叙述性文字（摘要、事项标题、日期），正文和说明都用系统无衬线。
- 等宽字体只用于路径、命令、代码、端口。时间和数字用无衬线的等宽数字（Mac `.monospacedDigit()`，网页 `font-variant-numeric: tabular-nums`）。
- 不用斜体、不用全大写、不加字间距。
- 正文行高 1.5；宋体摘要 1.6。段落间距 = 一行正文的高度。

## 4. 形状与层次

- 圆角三级：控件 6、分组 10、浮层 14。嵌套时内层 = 外层 − 间距，间距大于外层圆角时内层直角。
- 页面是平的：不加阴影、不发光、不加毛玻璃。阴影只给菜单、弹窗、菜单栏面板这类真正浮起来的东西。侧栏和菜单栏面板透出后面的内容是产品规则，保留。
- 不卡片套卡片：卡片里的子项用分割线或留白分开，不再加底色框。
- 间距用 4 的倍数：4、8、12、16、24、32。
- 动画只用于状态变化（展开、出现），时长 0.2 秒以内，不做悬停放大。

## 5. 文案与数字

- 能用布局和控件说清楚的不写说明；说明一句话说完，不用括号补充。
- 不用 `·` 拼接，改用逗号或分栏；"3 段，共 11 秒"。
- 数字带单位且说明指什么："活跃 9 小时 27 分""12 条"；千位用逗号；时长 ≥ 1 小时写"x 小时 y 分"，不足 1 分钟写"不到 1 分钟"。
- 文件大小只在详情里出现，列表里不出现字节数。
- 删除等不可逆操作才二次确认；可撤销的操作直接执行，给撤销。危险按钮只染文字，不铺红底。

## 6. 自查

- 这一页有几种字号、几种颜色？
- 每一段说明删掉以后，用户还能不能看懂？能的话就删掉。
- 窗口拉到最小（Mac 1080×640）和最大时，网页在 390px 宽时，有没有截断、重叠、横向滚动？
- 深色、浅色都看一遍。

## 7. 设置回归检查

原生设置不能把按钮藏在合并的静态辅助功能文本里。2026-11-12 的回归场景：macOS 分组 Form 中，`LabeledContent` 内的按钮可见，但辅助功能树只暴露标签。交互行统一使用保留子控件的 `SettingsRow`。

每次修改设置布局后，在安装后的应用检查：

1. 数据源详情开启一个可运行的来源，辅助功能树里必须有独立的“运行”按钮，点击后运行时间与结果更新。停用后配置仍可见。
2. AI 工具每项的连接/断开、AI 模型的测试连接、后台服务的浏览器入口、维护操作都必须暴露独立按钮；检查时不实际断开现有工具、不执行破坏性操作。
3. 安装示例插件：必填配置空值会报错；填好后安装默认停用，配置输入框只显示一次标签；更新重新展示权限并保留兼容配置，取消不改变安装内容。
4. 全局暂停时已启用来源仍保留开关选择；恢复后继续运行。登录自启关闭再开启时，当前三个服务的 PID 不变；安装升级保留自启选择。
5. 卸载弹窗提供保留记录与真删记录两个明确选项；真删链路在隔离数据库里运行 HTTP 验证，不删除真实记录做试验。
